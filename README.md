## 🛠️ Things I'm building

### 📓 Daybook

A private, lightweight place for journaling, reflection, and keeping track of life.

Built around a simple idea:

**writing software shouldn't get in the way of writing.**

---

### 🗂️ Roam

A personal home for notes, ideas, thoughts, references, and everything that doesn't belong anywhere else.

Designed to make capturing information nearly frictionless.

---

### 📚 Shelf

A personal reading tracker built around books rather than dashboards.

Track what you're reading, where you are, what you've finished, and what you want to read next.

Built as an iPhone-first web app with offline support.

---

### 🌑 Veil

Software for exploring money, markets, financial data, and decision-making.

An ongoing experiment in making complicated financial information easier to understand and actually useful.

---

## 🧩 How I like to build

I tend to prefer software that is:

* ⚡ fast
* 📱 mobile-first
* 📴 offline-capable when possible
* 🧠 simple enough to understand
* 🛠️ powerful without looking complicated
* 🎯 useful before impressive
* 🔒 private by default where it makes sense
* 🧭 built around real workflows
* ✂️ stripped of unnecessary friction

I have a soft spot for software that almost disappears once you start using it.

The interface should help you think, not make you think about the interface.

## 🧭 The philosophy

I don't care much whether something qualifies as a:

`startup`
`side project`
`tool`
`experiment`
`product`
`prototype`
`over-engineered solution to a minor inconvenience`

If it's interesting enough, I'll probably build it.

Some projects become serious.

Some stay tiny.

Some get rewritten three times.

Some exist because I wanted one button to behave differently.

That's part of the fun.
